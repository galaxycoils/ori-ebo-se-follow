- Desktop verification passed 47 replay and transport scenarios (including `ORI_SLOW=1`), the native sanitizer run (`make test-asan`), and the 18,000-frame synthetic soak (`make bench`: `18000/18000` tracked, `0` missed deadlines, `wheels_touched: false`).
